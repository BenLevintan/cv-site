Matrix Mask Picker

Visual binary matrix editor for optical hardware calibration

View on GitHub

Context

Developed for the physics department of a major Israeli defense technology company, this tool was created to assist engineers and physicists with complex experimental analysis.

In advanced optical systems, hardware components must be selectively enabled or disabled via binary mask configurations. Editing these masks as raw JSON or CSV is incredibly error-prone, so this application provides a fast, visual interface for visualizing, editing, and safely managing that critical matrix data.

Features Grid

Visual Cell Toggling

Click any cell to instantly flip its state between active (green) and inactive (blue).

JSON + CSV Support

Easily load structured JSON configurations and export flat CSV matrix maps.

Master/Slave Sync

Dual-panel view allowing engineers to overwrite a slave matrix via the master panel.

All On / All Off

Global reset functions for rapid blanket testing of hardware systems.

Save to CSV

Outputs standardized CSV strings optimized for optical hardware ingestion.

Two Matrix Formats

Adaptive grid system specifically designed to handle 12x12 and 15x16 arrays.
