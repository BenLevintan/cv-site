Overview

During my time as a Student Intern at Ludan Group (July 2024 – May 2025), I developed this Python solution to ensure data integrity and synchronization between centralized cloud spreadsheets and local file system documents.

The core script automates the comparison, filtering, and reporting of documents, identifying any missing or mismatched files between the master document list in Google Sheets and the documents present in the local directory structure.

By normalizing non-standard local file names and intelligently mapping them to the cloud index, this tool drastically reduced manual cross-referencing efforts and ensured up-to-date document tracking.

Features Grid

Google Sheets Integration

Connects directly to Google Sheets master documents using the official Google Sheets API and the gspread library for seamless data extraction.

Secure Authentication

Utilizes Google Cloud OAuth 2.0 and service account credentials (JSON) for secure, token-based programmatic access without user intervention.

File System Scanning

Recursively traverses local folder structures, identifying all relevant documents while selectively filtering out irrelevant extensions (.bak, .log, .db).

Intelligent Normalization

Custom Regex-powered Python utilities intelligently fix inconsistencies in local file and folder naming conventions to match the master list.

Automated Reporting

Generates detailed text reports highlighting exactly which documents are listed in the cloud but are missing or mismatched locally.

Enhanced Monitoring

Designed to be extensible, interfacing with custom external JavaScript scripts for further web-based data monitoring and presentation.

def file_name_fix(file_name):
    # Extract the main part of the file name before "_sheet" or "SHT"
    main_part_match = re.match(r"^([A-Za-z0-9-]+)", file_name)
    if not main_part_match:
        return file_name

    main_part = main_part_match.group(1)
    
    # Standardize incorrectly formatted 'SHT' additions (e.g., DOC123SHT1 -> DOC123-SHT001)
    incorrect_sht_match = re.search(r"([A-Za-z0-9-]+)SHT(\d{1,3})", file_name, re.IGNORECASE)
    if incorrect_sht_match:
        main_part = incorrect_sht_match.group(1)
        number = incorrect_sht_match.group(2)
        formatted_number = number.zfill(3)
        return f"{main_part}-SHT{formatted_number}"
    
    return main_part
Regex-based normalization utility to standardize human-entered filenames for accurate programmatic comparison.
