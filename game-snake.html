About This Game

Guide your snake across the grid. Eat the red food. Grow longer. Don't hit the walls. Don't eat yourself. Simple rules. Unforgiving consequences.
FEATURES
Classic grid-based movement with arrow key controls. Randomized food spawning. Score tracking. Instant restart on death. Zero loading screens. Zero microtransactions. Zero loot boxes.
BUILT FROM SCRATCH
No game engine. No frameworks. Pure vanilla JavaScript and an HTML5 canvas element. The entire game logic fits in one file.
